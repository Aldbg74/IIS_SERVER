SIO.DOMAINE — GUIDE DU PORTAIL INTRANET

1. Le portail est un site statique compatible avec Microsoft IIS.
2. Les liens, documents et contacts se configurent dans assets/config.js.
3. Les URL laissées vides sont volontairement signalées « À configurer ».
4. Ne publiez jamais de mots de passe, jetons API ou secrets dans les fichiers du site.
5. Les liens ne constituent pas un contrôle d'accès. Protégez séparément GLPI, Wazuh et les consoles.
6. L'intranet ne vérifie pas l'état des serveurs et ne se connecte pas à Active Directory.
7. Vous pouvez placer vos PDF dans le dossier docs/ et modifier les URL correspondantes.
